# v0.3 — Full Proxy Client Foundation

Objective: make FlowProbe a credible sing-box desktop client while retaining capture plumbing.

Required: local/remote sing-box profiles, refresh/switching, selector and URLTest control, node/group status, connection view, DNS/routing basics, raw advanced JSON editor, validate/format/diff/apply workflow, compiled-config viewer, protected system overlay.

Exit: a power user can run a normal sing-box profile through FlowProbe, switch selectors, inspect the final compiled config, and enable/disable capture without rewriting the user's proxy policy.
