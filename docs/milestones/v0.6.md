# v0.6 — Analyzer Platform v1

Objective: freeze the first useful third-party semantic analyzer SDK.

Required: WIT/Component Model v1, plugin manifest and permission model, Wasmtime sandbox/resource limits, normalized-event/history APIs, semantic output, analyzer-scoped storage, declarative views, install/enable/disable/update UX, replay against captures, compatibility negotiation, examples/docs.

Exit: an external plugin author can build an analyzer without importing FlowProbe internals, and the host can deny sensitive payload access while still running metadata-only analyzers.
