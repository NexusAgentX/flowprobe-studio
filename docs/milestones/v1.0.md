# v1.0 — Production Hardening

Objective: stable public release baseline.

Required: supported installers/upgrades on Windows/macOS/Linux, destructive network recovery tests, CA hardening, secure IPC/privilege review, parser fuzzing, large-session resource limits, plugin sandbox review, release signing/notarization plan, migration/backward-compatibility policy, privacy/security docs, E2E acceptance for all four runtime modes.

Exit: release checklist is green on supported platforms and no known critical issue can leave networking, trust store, captured secrets, or plugin permissions in an unsafe state.
