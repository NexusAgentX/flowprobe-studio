# v0.2 — Reliable TUN & System Integration

Objective: make the architecture proof a safe daily network layer on Windows, macOS and Linux.

Required: transactional TUN lifecycle, crash rollback/watchdog, privileged helper boundary, CA install/uninstall, direct and external HTTP/HTTPS/SOCKS5 egress, process-aware loop prevention/capability reporting, local upstream process detection, UDP/DNS baseline visibility, platform integration tests.

Exit: start/stop/crash recovery cannot leave supported test machines without ordinary connectivity; loop-prevention tests pass for both built-in direct and local external proxy paths.
