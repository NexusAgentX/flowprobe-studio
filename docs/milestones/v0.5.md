# v0.5 — Replay & Active Debugging

Objective: add deliberate traffic-debugging mutations while keeping passive capture safe by default.

Required: repeat request, edit-and-send, compare, rewrite rules, breakpoint/intercept, map local/remote, delay/throttle/drop primitives, visible rule state and mutation audit trail.

Exit: Passive and Debug modes are unambiguous; no mutation rule can silently affect traffic while the product reports passive capture mode.
