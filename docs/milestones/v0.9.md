# v0.9 — Plugin Ecosystem & Product Polish

Objective: make analyzers discoverable/manageable and polish the proxy-capture-analyze workflow.

Required: signed/trusted plugin metadata model, registry UI, permission review, plugin developer CLI/templates, additional reference analyzer, polished navigation, diagnostics bundle, accessibility/keyboard workflows, update/migration framework.

Exit: users can understand what a plugin can read/do before enabling it, and plugin lifecycle does not require manual edits to application internals.
