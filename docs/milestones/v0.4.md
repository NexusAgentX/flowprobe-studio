# v0.4 — Capture Workbench

Objective: deliver a strong passive Reqable/Charles-class traffic inspection workflow.

Required: robust HTTP/1.x/2, TLS metadata/interception fallback, SSE, WebSocket, useful gRPC visibility, request/response viewers, rich filtering/search, sessions/markers, storage/retention limits, raw discovery mode, HAR/session import-export, deterministic replay into decoders.

Exit: common desktop/CLI HTTPS traffic can be captured, searched, inspected and exported without active mutation and without requiring product-specific analyzers.
